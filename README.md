# NMS — Network Management System

نظام إدارة الشبكة (**NMS**) هو منصة مفتوحة المصدر لإدارة ومراقبة البوابات الشبكية والراوترات المبنية على Linux/ucode، بواجهة عربية حديثة (RTL) وبنية ثنائية العزل (`noc-apid` + `noc-helperd`) تضمن الأمان والسرعة وانخفاض استهلاك الموارد (~39 MB RAM).

---

## المزايا الرئيسية (Core Features)
* **الأداء العام والمنافذ:** مراقبة حية للمعالج، الذاكرة، القرص، جلسات `conntrack`، ومعدل تدفق جميع المنافذ عبر البث اللحظي (`SSE`).
* **شجرة المسارات الحية (Interactive Topology):** خريطة تفاعلية حية من الإنترنت إلى الراوتر ثم الأجهزة المتصلة مع تدرج حراري للسرعة، وفحص اتصال فوري (`Ping`)، وتكبير/تحريك حر.
* **إدارة العملاء والتحكم بالوصول:** اكتشاف تلقائي للأجهزة المتصلة، حظر فوري عبر `nftables`، وتحديد سرعة الرفع والتنزيل، وإدارة عقود `DHCP` الثابتة.
* **تصفية DNS والجدار الناري:** تكامل مباشر مع `AdGuard Home`، وإدارة مناطق `fw4` وتوجيه المنافذ و`SQM / CAKE`.
* **الأمان والعزل:** مصادقة ثنائية (`TOTP`)، وعزل الصلاحيات بين خادم الويب (`noc-api`) ومحرك التنفيذ (`noc-helperd`)، وتراجع تلقائي (`Auto-Rollback`) عند تعذر الوصول بعد تعديلات الشبكة.
* **البحث الشامل السريع (`Ctrl+K`):** لوحة أوامر وبحث فوري في التبويبات والأجهزة والقواعد.
* **دعم كامل للغتين العربية والإنجليزية (`EN / عربي`):** تبديل فوري بين العربية (`RTL`) والإنجليزية (`LTR`) دون إعادة تحميل الصفحة.

## التثبيت السريع (Quick Install)

انسخ المستودع إلى جهازك أو الراوتر، ثم نفّذ أمر التثبيت:

```sh
git clone https://github.com/heshamhak/NMS-Network-Management-System-.git
cd NMS-Network-Management-System-
sh scripts/install.sh
```

بعد اكتمال التثبيت، سيظهر لك رابط الدخول ورمز التهيئة الأولية:
* **رابط الواجهة:** `http://<ROUTER_LAN_IP>:8780/`
* **رمز التهيئة الأولية:** `/etc/noc-console/bootstrap.token`

### الإزالة (Uninstall)
```sh
sh scripts/uninstall.sh          # إزالة الخدمات والملفات مع الإبقاء على الإعدادات
sh scripts/uninstall.sh --purge  # إزالة كاملة شاملة للإعدادات والمفاتيح
```

## بنية المشروع (Repository Structure)

```text
nms-opensource/
├── backend/
│   ├── noc-apid          # خادم HTTP/API/SSE وإدارة الجلسات (ucode)
│   └── noc-helperd       # محرك التنفيذ النظامي المعزول (ucode)
├── frontend/
│   ├── index.html        # الهيكل الرئيسي للواجهة (RTL + CSP strict)
│   ├── styles.css        # نظام الألوان والتصميم (Soft Light-Black + Blue)
│   ├── app.js            # وحدة التحكم الرئيسية وتحديث DOM
│   ├── noc-topology.js   # محرك شجرة المسارات الحية التفاعلية
│   ├── noc-search.js     # البحث الشامل ولوحة الأوامر (Ctrl+K)
│   ├── noc-tools.js      # أدوات الفرز والتصفية والبحث في الجداول
│   ├── netchart.js       # محرك الرسوم البيانية المخصصة
│   ├── nms-i18n.js       # محرك الترجمة الثنائي (العربية / الإنجليزية)
│   ├── manifest.json     # بيانات تطبيق الويب التقدمي (PWA)
│   └── sw.js             # Service Worker للتخزين المؤقت
├── init.d/
│   ├── noc-helperd       # سكربت تشغيل الخدمة المساعدة
│   └── noc-apid          # سكربت تشغيل خادم الواجهة
├── schemas/
│   └── noc_schemas.json  # عقود التحقق من البيانات والـ API
├── scripts/
│   ├── install.sh        # المثبّت التلقائي
│   └── uninstall.sh      # أداة الإزالة النظيفة
├── tests/
│   └── verify_noc_p15.py # اختبارات التحقق والأمان والتباين
└── LICENSE               # رخصة MIT
```
